# Composite Analysis and Statistical Significance Test

## Overview

Composite analysis is widely used in climate science to investigate the impacts of large-scale climate phenomena such as ENSO.

This module demonstrates how to classify ENSO events, compute composite anomalies, and evaluate statistical significance using Student's t-test.

## Contents

- ENSO index analysis
- El Niño / La Niña event classification
- Composite SST anomaly analysis
- Student's t-test
- Correlation map
- Statistical significance mask

## Learning Objectives

- Understand composite analysis
- Perform event classification
- Conduct hypothesis testing
- Produce significance maps
