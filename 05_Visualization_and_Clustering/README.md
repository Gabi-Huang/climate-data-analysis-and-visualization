# Climate Visualization and Clustering

## Overview

This module introduces visualization techniques and unsupervised machine learning methods for climate datasets.

## Contents

- Heatmaps
- Hovmöller diagrams
- K-Means clustering
- Climate regime analysis

## Learning Objectives

- Visualize multidimensional climate datasets
- Apply clustering algorithms
- Interpret climate regimes
